BIRTHDAY POP-UP UPDATE

The birthday pop-up is included across the HTML pages and is controlled by birthday-popup.js. It appears on October 28 using Africa/Lagos time, then automatically stops appearing after that date. It is shown once per visitor per year after they close it. No manual removal is required.

To publish: upload/replace the updated site files in your existing GitHub Pages repository. Keep your existing assets, CNAME, robots.txt, sitemap.xml, and AI Worker setup. The birthday popup does not need an API key or paid service.
